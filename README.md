Job Portal Management System
Project Overview

The Job Portal Management System is a dynamic web application developed using HTML, CSS, JavaScript, PHP, MySQL, Apache Web Server, and phpMyAdmin. The system provides an online platform where job seekers can register, log in, browse available jobs, apply for suitable positions, and manage their profiles. It also includes an administrator panel that allows the admin to manage job postings, monitor job applications, and manage the overall recruitment process. The project integrates frontend development, backend programming, and database management to provide a secure, efficient, and user-friendly recruitment platform.

How to Run the Project
Install XAMPP on the system.
Copy the JobPortal project folder into the htdocs directory.
Start the Apache and MySQL services from the XAMPP Control Panel.
Open phpMyAdmin and create or import the jobportal database.
Create the required tables: users, jobs, applications, and admin.
Insert sample job records into the jobs table.
Open a web browser and enter http://localhost/JobPortal/.
Register a new account or log in with an existing account.
Browse available jobs and apply for suitable positions.
Log in as an administrator to manage job postings and monitor job applications through the admin dashboard.
